# the_BELT_threeM

> 전북대학교 큰사람 장학 프로젝트 통합 관리 앱

---

## 프로젝트 개요

| 구분 | 내용 |
|------|------|
| 프로젝트명 | 교내 장학 프로젝트 관리 앱 |
| 개발 기간 | 2023.06 ~ 2023.08 |
| 팀 구성 | 3명 (기여도 40%) |
| 핵심 목표 | 전북대학교 '큰사람 프로젝트' 과제 수행 관리 및 공지사항 통합 제공 |
| 주요 성과 | 학생들의 꾸준한 장학금(큰사람 벨트) 달성 지원 및 관리 자동화 |
| 주요 기술 | Android (모바일 앱), Python (웹 크롤링), Django REST Framework (서버/API) |

이 프로젝트는 "컴퓨터공학은 분야를 막론하고 도움이 될 수 있는 학문"이라는 조언에서 출발하여, 전북대학교 학생들이 가장 가까이에 있는 기회인 **큰사람 벨트** 장학 프로젝트를 꾸준히 수행하고 관리할 수 있도록 돕는 애플리케이션이다.

---

## 배경 및 문제 해결

### 배경

전북대학교의 '큰사람 벨트'는 사전 조건이나 분위에 상관없이 얻을 수 있는 장학금이지만, 다양하고 어려워지는 과제로 인해 꾸준한 관심과 노력이 요구된다.

### 기존 문제점

- **꾸준함 유지 어려움**: 학업과 취업을 병행하는 대학 생활에서 개인의 노력만으로 장기간 꾸준함을 유지하기 어려움
- **정보 분산**: 큰사람 관련 공지사항이 올라오는 장소나 시간이 통일되어 있지 않아 정보 획득이 어려움

### 해결 목표

전북대 학생이라면 누구나 가까이에 있는 장학 기회를 놓치지 않도록, 큰사람 프로젝트 수행을 통합적으로 관리하고 공지사항을 모아 제공하는 애플리케이션을 개발하자!

## 백엔드 상세 (Django REST Framework)

### 데이터 모델 (`models.py`)

공지사항 데이터를 저장하는 `JBNU` 모델:

| 필드 | 설명 |
|------|------|
| `jid` | 공지사항 ID (Primary Key) |
| `jtitle` | 공지사항 제목 |
| `jbelt` | 공지사항 벨트 (카테고리) |
| `jurl` | 공지사항 URL |
| `jdate` | 공지사항 날짜 |

### API 엔드포인트 (`urls.py`)

`ViewSet` + `Router` 방식으로 자동 라우팅:

| Method | Endpoint | 설명 |
|--------|----------|------|
| `GET` | `/JBNUs/` | 공지사항 목록 조회 |
| `POST` | `/JBNUs/` | 공지사항 등록 |
| `GET` | `/JBNUs/{jid}/` | 특정 공지사항 조회 |
| `PUT` | `/JBNUs/{jid}/` | 공지사항 수정 |
| `DELETE` | `/JBNUs/{jid}/` | 공지사항 삭제 |

### 배포 환경

| 항목 | 내용 |
|------|------|
| 플랫폼 | Koyeb (클라우드 배포) |
| 서버 | Gunicorn + WhiteNoise (정적 파일) |
| DB (운영) | PostgreSQL (환경변수로 연결) |
| DB (로컬) | SQLite (fallback) |
| 배포 설정 | `Procfile`, `koyeb.json` |

## 개발 과정 및 기술적 구현

### 1. 프론트엔드 (Android)

- **개발 환경 수립**: Android Studio 기반으로 기능 및 화면 구성 회의, 개발 파트 분류
- **핵심 UI/UX 구현**: 메뉴 화면 전환, List View 편집, Home 화면 및 앱 테마 구현
- **상세 기능**: Floating Action Button을 이용한 할 일 생성, 알림 생성 및 다이얼로그 연결, PDF 뷰어 디자인 커스터마이징
- **정보 연동**: 서버와 앱 연결을 통한 공지사항 페이지 완성 및 벨트 포인트 합계 계산 로직 구현

### 2. 백엔드 / 데이터 (Python, Django REST Framework)

- **웹 크롤링 설계**: Python을 이용하여 전북대 공지사항을 크롤링하고, 게시글 선별 기준을 회의하여 설정
- **API 구현**: Django REST Framework를 학습하고, 크롤링한 공지사항을 앱으로 제공할 DB 및 REST API 구현
- **서버 배포**: Koyeb 가입 및 연동 학습 후, Django 실험 서버 배포 성공 및 최종 크롤링 서버 배포 완료 (공지사항이 벨트에 맞게 저장되는지 실험 포함)
