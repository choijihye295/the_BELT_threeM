# the_BELT_threeM
교내 장학 프로젝트 관리 앱

## 프로젝트 개요
| 구분 | 내용 |
| :--- | :--- |
| **프로젝트명** | 교내 장학프로젝트 관리 앱 개발 |
| **기간** | 2023.06 ~ 2023.08 |
| **팀구성** | 3명 (기여도 40%) |
| **핵심 목표** | 전북대학교 '큰사람 프로젝트' 과제 수행 관리 및 공지사항 통합 제공 |
| **주요 성과** | 학생들의 꾸준한 장학금(큰사람 벨트) 달성 지원 및 관리 자동화 |
| **주요 기술** | Android (모바일 앱), Python (웹 크롤링), Django REST Framework (서버/API) |

이 프로젝트는 "컴퓨터공학은 분야를 막론하고 도움이 될 수 있는 학문"이라는 조언에서 출발하여, 전북대학교 학생들이 가장 가까이에 있는 기회인 '큰사람 벨트' 장학 프로젝트를 꾸준히 수행하고 관리할 수 있도록 돕는 애플리케이션을 개발.

## 배경 및 문제 해결
### 배경
전북대학교의 '큰사람 벨트'는 사전 조건 없이 얻을 수 있는 유일하고 가까운 장학금이지만, 다양하고 어려워지는 과제로 인해 꾸준한 관심과 노력이 요구됨.

**기존 문제점**
꾸준함 유지 어려움: 학업과 취업을 병행하는 대학 생활에서 개인의 노력만으로 장기간 꾸준함을 유지하기 어려움.
정보 분산: 큰사람 관련 공지사항이 올라오는 장소나 시간이 통일되어 있지 않아 정보 획득이 어려움.

**해결 목표**
전북대 학생이라면 누구나 가까이에 있는 장학 기회를 놓치지 않도록, 큰사람 프로젝트 수행을 통합적으로 관리하고 공지사항을 모아 제공하는 애플리케이션을 개발하자!

## 주요기능
| 기능 | 주요 내용 | 사용자 경험 (UX) |
| :--- | :--- | :--- |
| **홈 화면** | 현재 포인트 및 벨트 현황을 시각적으로 보여줌. | 벨트 이수 시 메인 페이지의 이미지가 변하게 구현하여 **동기 부여**. |
| **할 일 목록 (리스트)** | 장학 프로젝트 관련 할 일 생성, 수정, 완료 체크 기능 제공. | 체크 시 홈 화면의 포인트 및 벨트에 **자동 반영**되어 실시간 성과 확인 가능. |
| **공지사항 화면** | Python 웹스크래핑으로 가져온 학교 장학 프로젝트 관련 활동 공지를 통합 제공. | **벨트별 스피너 필터링** 기능을 구현하여 맞춤 정보 제공. |
| **매뉴얼 화면** | 큰사람 프로젝트 PDF 매뉴얼을 앱 내에서 제공. | **PDF 뷰어 디자인 커스터마이징 및 확대/축소 기능** 구현. |
| **알림 기능** | 사용자 설정에 따라 할 일 목록 관련 알림을 생성하여 꾸준한 관리를 지원. | 알림 생성과 **다이얼로그 연결 기능**을 통해 정보 수신 용이. |

## 개발 과정 및 기술적 구현
1. 프론트엔드 (Android)
- 개발 환경 수립: 안드로이드 Studio 기반으로 기능 및 화면 구성 회의, 개발 파트 분류.
- 핵심 UI/UX 구현: 메뉴 화면 전환, List View 편집, Home 화면 및 앱 테마 구현.
- 상세 기능: **Floating Action Button**을 이용한 할 일 생성, 알림 생성 및 다이얼로그 연결, PDF 뷰어 디자인 커스터마이징.
- 정보 연동: 서버와 앱 연결을 통한 공지사항 페이지 완성 및 벨트 포인트 합계 계산 로직 구현.

2. 백엔드/데이터 (Python, Django REST Framework)
- 웹 크롤링 설계: $\text{Python}$을 이용하여 학교 공지사항을 크롤링하고 게시글 선별 기준을 회의하여 설정.
- API 구현: $\text{Django REST Framework}$를 학습하고, 크롤링한 공지사항을 앱으로 제공할 DB 및 API 구현.
- 서버 배포: Koyeb 가입 및 연동 학습 후, Django 실험작 서버 배포 성공 및 최종 크롤링 서버 배포 완료. (공지사항이 벨트에 맞게 저장되는지 실험)
